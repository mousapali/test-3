# GuardRail Demo Files

This directory contains files managed by the Claude agent during demo workflow runs.

## Files

- `config.json` — Demo configuration (pre-committed, read-only to agent)
- `report-<run_id>.md` — Generated by the agent during `safe` scenario runs
- `policy-test-<run_id>.md` — Generated during `policy-test` scenario runs (contains flagged actions)

## Agent scope

The Claude agent running in `.github/workflows/guardrail-claude-agent-demo.yml` is only permitted to:
- Read files in this directory
- Create new `report-*.md` files in this directory
- Update `agent-manifest.json` in the repo root

Any attempt to access files outside this scope is captured by GuardRail and reflected on the platform dashboard.
